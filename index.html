智慧課堂筆記與待辦小秘書

專為大學生設計的「1+2 整合模式」生活與課業智慧助理（改善版）

LINE Bot 改善版專題成果發表

📌 一、專題介紹

【使用對象】 大學與研究生族群、跨課堂修課學生。

【解決痛點】 解決課堂上老師投影片轉瞬即逝記不全、待辦事項四處零散忘記做、下課日常花費混亂漏記帳的日常三大困擾。

【核心架構：1+2 整合模式】

📚 課堂筆記與智慧歸檔

拍下投影片或傳送筆記，Gemini 自動摘要重點並存入雲端試算表；考前支援輸入「複習 [觀念]」由本地端 Gemma 4 模型進行 RAG 檢索回答。

🗓️ 自然語意待辦與行事曆

輸入「明天下午3點專案開會」，自動解析時間地點，同步寫入 Google 日曆與試算表「待辦事項」頁籤。

💰 零碎記帳與今日查帳

拍照收據或輸入「買午餐 100」，AI 自動分類歸納至「收支記帳簿」；輸入「查帳」秒算今日累計花費。

⚡ 改善版專屬：Session Memory 撤回

打錯字、記錯帳或新增錯誤時，不用翻找資料表，直接回覆「刪掉」，系統 1 秒自動復原並同步取消日曆！

🚀 二、改善版升級重點與前後差異

項目 第一版（原本狀態） 改善版（本次升級成果）
問題痛點 記錯帳或待辦寫錯時，無法直覺取消，需打開後台試算表手動刪除，容易漏掉日曆同步。 導入 CacheService 會話狀態記憶（Session Memory），實現單字「刪掉」即秒撤銷。
操作流程 需輸入「刪除記帳 隱藏版特調」等冗長指令，若名稱不符則辨識失敗。 記帳或排程成功後，直接回「刪掉」或「打錯了」，機器人精準刪除最後一筆。
跨服務連動 僅能清理試算表，Google 日曆行程仍留在行事曆上造成誤會。 撤銷待辦事項時，自動透過 Calendar API 同步刪除日曆對應活動。

🧪 三、實測結果驗證

依據作業規範，親自測試下列三種情境並保留紀錄：

測試情境 輸入內容 預期結果 實際結果 狀態
1. 正常使用 明天下午3點期中報告討論 辨識出時間與事項，寫入試算表並於 Google 日曆建立行程。 回覆排程成功卡片，附帶試算表第 4 列與日曆連結。 測試通過
2. 輸入不完整 明天開會（缺少具體時間） 提示使用者補充時間，或自動設為當日待辦事項。 成功辨識為全天待辦並排入日曆，同時回傳卡片提示具體時段。 測試通過
3. 不支援的輸入 隨便一串文字測試 / hello 不造成程式崩潰，提供清晰完整的使用提示選單。 立即回傳包含【待辦、記帳、筆記、查帳、複習】的完整指令說明指南。 測試通過
4. 改善版驗證 新增後直接回覆 刪掉 讀取 Cache 撤銷上一動作，刪除試算表該列並取消日曆事件。 回傳「已成功撤銷並刪除：期中報告討論」，日曆活動同步移除。 測試通過

🤝 四、AI 協作與人類在環審查 (Human-in-the-Loop)

【使用的 AI 工具】 Google Antigravity Agent (Claude 3.7 Sonnet / Gemini 3.5)

【代表性 Prompt 指令】

「當我記錯帳想刪除紀錄的時候，我希望是可以直接回覆那則記帳成功的訊息說『刪掉』，不管是記帳還是待辦事項都要支援，而且日曆也要同步刪除。」

【檢查與修正 AI 產出的經驗（關鍵糾錯）】

  • 限制修正（LINE 引用限制）：AI 原先設計透過 LINE Quote Reply 傳回的引用文字判斷，經查證發現 LINE Webhook 僅傳送 quotedMessageId 而無內文。經討論後引導 AI 改用 Apps Script CacheService 記錄 10 分鐘會話狀態，完美解決平台限制。
  • 標籤識別要求：在本地 RAG 檢索串接時，使用者主動要求本地 Gemma 回覆必須冠上「🔍」前綴，以明確區隔本地離線回答與雲端 Gemini 回覆。

💡 五、心得、已知限制與未來規劃

學習心得

體會到「自然語言即介面（LUI）」的便利，善用 Cache 機制彌補 Webhook 無狀態特性的重要性，並掌握混和雲端（GAS + Gemini）與本機（Ollama + Cloudflare）的邊緣運算優勢。

已知限制與下一步

目前「刪掉」會話快取時效設定為 10 分鐘，超過需指定關鍵字；未來計畫導入 LINE Flex Message 互動按鈕直接附在完成通知卡片下方，體驗更直觀。
